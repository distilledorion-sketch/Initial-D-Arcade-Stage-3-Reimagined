POST-RACE TUNING PREVIEW CRASH - October 10, 2026

Reported screenshot
Version 0.3.95-community-replays.46, Race 3, InvalidOperationException:
invalid vector subscript at Idas3SceneGame.Update offset 0x947.
The published assembly MVID 9df055ddb0dd41d6a2526d7f83679aec matches the
preserved .46 player. Cecil maps that offset to constructing the exception
after Idas3SceneStep returns failure. The message is copied from native code.
Race 3 is Finished, rather than the third race or a track identifier.

Reproduced cause
A saved car can retain advanced engine upgrades while its basic package
tuning is unfinished. The source renewal/package-change operations produce
this state and the remake accepts it from a saved profile. The current App
does not appear to initiate the original card-renewal workflow itself.

When the last basic part is awarded, the profile's basic-step byte becomes
the next performance-upgrade index. The remaining basic-completion animation
starts the preview before sending its completion-focus event. The preview
previously treated that performance index as a basic part. The real App
reproduced invalid vector subscript with index 57 in a ten-step package,
engine level 63, on the fifth resumed result visit.

Fix
originalTuningPreviewFocus returns the intended completion focus, zero, when
the basic-complete flag is set. It does not access the former basic-step
table or modify the profile. Part-specific previews before completion and
performance/optional previews retain their existing behavior.

The screenshot alone does not establish this player's car/profile or exact
trigger. This is a reproduced and fixed path matching its exception and
finished-race state, not a claim that every possible vector exception is fixed.
