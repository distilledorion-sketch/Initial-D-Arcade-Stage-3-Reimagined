# Contributing

Use Issues for reproducible bugs and feature requests. Include the game version, track/direction, mode, weather/time of day, car, input device, and steps to reproduce. For performance reports, include CPU, GPU, resolution, graphics settings and approximate FPS before/after the affected section.

Screenshots and short videos help. Review logs before posting them and remove private information. Do not attach save folders, installation credentials, admin keys or unrelated personal files.

For code changes, keep pull requests focused and describe the resulting behavior and relevant verification. Preserve gameplay timing, input, personal save compatibility and existing course assets unless the change explicitly needs to alter them. Use isolated data for tests that modify progression or results.

A replay is supporting evidence, not proof that a player cheated. Report suspected leaderboard abuse privately to the project maintainer rather than making accusations in public issues.
