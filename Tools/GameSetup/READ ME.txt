Initial D Arcade Stage 3 Reimagined

Use Install Initial D Arcade Stage 3 Reimagined from the setup download and select the game folder.
Existing Windows players can also choose Update inside the game. Both paths
install the same player and run the same local setup on restart.
For a fresh manual install, extract the full Windows ZIP into a writable
folder and open InitialDUnity.exe once to run setup. After setup, launch
Initial D Arcade Stage 3 Reimagined.exe. Existing shortcuts to the original
name continue to work.
For first-time setup, choose either supported original Arcade Stage 3 disc:
  Japanese Rev C: GDS-0032C CHD with initdv3j.zip or 317-0379-jpn.pic.
  English: GDS-0033 CHD with 317-0384-COM.pic or an arcade ZIP containing it
  (setup checks initdv3e.zip and initdv3.zip).
Place the matching ZIP or PIC beside the CHD or in the game's rom folder.
You can also select the files when prompted. The ZIP provides the security
file needed to read the CHD. One matching pair supplies the complete base.
Options > Gameplay has two language settings. Custom Menu Language changes
Reimagined menus to English, Japanese, or Simplified Chinese when you apply it.
ROM Language selects the full English or Japanese Rev C arcade game on restart.
The first switch needs the selected region's CHD and matching security file.
Cancel the file picker to play the current ROM. Setup keeps each prepared region
in the game folder for later switches. Both versions use the same player saves.
Updates reuse verified files from a previous installation when they contain the data the new version needs.

Setup reads the disc and builds the local files for the original courses,
cars, sounds and interface. Leave the window open until setup finishes.
Setup copies the verified disc and security file into rom. Move the entire game
folder to keep the disc, extracted assets and player data together.
Open Verify Game Files.cmd to verify the installed cache, courses and music.
Installation logs are in InitialDUnity_Data\StreamingAssets beside the cache.

Open Options > Replays to watch a recording in the game window. Back to game
returns you to the same screen or paused race. Replay Viewer.cmd can also open
a local .idreplay recording in the running game.

Saves, settings, replays, online records, logs and game caches live in UserData.
On first play, close older Windows builds. The launcher moves previous game
files from this Windows profile into UserData, verifying each file first.
When another copy contains missing cards or settings, setup offers recovery.
Choose the folder whose cards, wheel/controller bindings and HUD you want.
For older installations on another drive, open Recover Saves and Settings.cmd
in the game folder. Close both games before restoring. Existing slots absent
from the source stay available. Replaced cards and settings are backed up in
UserData/Save recovery backups. The selected game folder keeps its originals.
The HUD includes the original meter, 113 alternate meters and 314 ornaments.
Saved meter styles, layouts, ornament choices and custom HUD artwork carry over.
If the previous settings backup contains a reset meter or ornament, setup can
restore those selections separately. The Xbox Menu button opens Pause during
a race. With default controls a free left-stick click operates arcade Start.
Windows, display drivers and online account services manage their own system data.

The original nine courses and full Stage 3 soundtrack come from your disc.
Extra songs and Sound Room tracks are included. The game runs with no mod maps.
To install an optional track, extract its ZIP into Mods\Maps beside the game.
Download mod maps at https://gamebanana.com/games/26479.
For example, the Enna Skyline pack creates Mods\Maps\ENNA. Existing course
installations are kept, including courses migrated from older game folders.
To make a car or HUD skin, open Mods\Texture Workshop.cmd and choose a car
or HUD bank. The workshop exports editable PNGs from your disc to
Mods\Workshop. Edit a PNG and copy it to the matching folder under Mods\Cars
or Mods\HUD. Keep its filename and pixel dimensions. Restart to see your
art in the game. HUD PNGs use your transparency. Car skins keep the
original texture's transparency.
Exporting again preserves your edits. Remove the installed PNG and restart
to return that texture to its original appearance.

For in-race panel colors, edit Mods\HUD\Race Colors.json and restart.
Use a six-digit RGB tint such as "#FF8800" for timer or "#80FFFF" for
minimap. White ("#FFFFFF") keeps the original colors. Each entry affects
one panel; mirrorFrame changes the surround only. The meter tint works
with the original meter and installed alternate meters.

For replacement artwork choose Export in-race HUD textures. Use game2d for
the original dial, timer and race messages (texture_027.png holds the main
countdown digits and texture_009.png the clock digits); game2d_sprites for speed and
gear; game2d_ta for records; and cupwater for the paper cup. navigation/<code>
contains the original course's map, frame and driver markers. faces/<driver>
contains rival portraits. Imported courses draw their minimap from the route
and use the minimap tint. After editing, install only the PNGs you changed.

To try a first mod, choose the cyan needle in the workshop and race with the
original meter. Its file is Mods\HUD\game2d\texture_053.png. To share
your own skin, zip your edited PNGs with their folder paths starting at Cars
or HUD. Another player can extract that ZIP into Mods and restart. Back up
an existing skin before replacing a PNG with the same name.

Cars use the installed model folder names (for example, toyota_ae86t).
HUD includes game2d for the original meter and game2d_sprites for race
sprites.

TRACK MODS
Extract each track pack into its own folder in Mods\Maps. Keep the nine
official folder names reserved for their original packs. Open Time Attack
and select MODS. New folders are detected at startup and while choosing a
course. Use the wheel, directional buttons or keys to scroll through the list.
Restart after replacing or removing a track that was already loaded.

Track authors can use HAKONE as a file layout example. Supply the Stage 8
exported race.bin, lamps.bin, menu.idastex (two images), road.bin, scene.bin,
scene.json, the referenced DDS textures, and one set of <slug>_path.bin,
<slug>_path_l.bin, <slug>_path_r.bin and <slug>.rcl. Optional day_wet,
night_dry and night_wet folders contain scenery in the same format. Missing
variants use the base scenery. Use lowercase a-z, digits and underscores in
<slug>. Extract a ZIP before dropping the folder in.

For a stable ID across geometry edits, add track.json to your pack:
  {"key":"yourname.ridge-pass","name":"Ridge Pass"}
Use a unique lowercase key and keep it across compatible updates. Give a new
layout its own key. Set the optional "direction" to "downhill", "outbound" or
"clockwise" for matching forward and reverse labels. The default is downhill.
Without track.json the game uses the folder name for display
and the main path file for identity. Renaming the folder preserves the ID.
Distinct packs with the same identity cannot be installed side by side.
Times and ghosts are local. To play a shared replay, install its track pack.
Extra race songs use 160 kbps MP3 with their source loop positions.
The Season 5 songs keep their existing Ogg Vorbis audio and loop data.
The built-in courses accept community times. In the Mods list, supported
tracks are marked COMMUNITY LEADERBOARD SUPPORT in red.
Other mod tracks use local records and replays. Both online drivers need the
chosen track installed.
On supported Windows NTFS drives it also compresses large game files to save
disk space. The courses, textures, and music keep their original quality.

For an existing installation, close the game before using the standalone setup.
It reuses your local ROM and previously verified game files.
Upgrading the original Windows release builds its disc cache before retiring
the previous assets. Altered or unrecognized previous assets are kept under
UserData/Previous Windows Assets. If you supplied CUE/BIN files to the old
player, select your GDS-0033 or GDS-0032C CHD when asked. Leave setup open until it finishes.
The Windows player and conversion tools run locally. No Python installation,
Unity Editor or external downloads are required for setup.
